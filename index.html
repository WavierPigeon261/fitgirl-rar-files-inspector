Verify Multi-Part RAR Archives Before Extraction

A native, high-performance Windows desktop application designed to inspect multi-part RAR downloads from sites like FitGirl Repacks, detecting missing parts, broken sequence numbers, and path length errors before extraction.

Built for Speed & Accuracy

Designed to save time and eliminate extraction errors before running unarc.dll routines.

⚡

Multi-Part Verification

Scans multi-part archive sequences to detect missing files, broken numbering patterns, or truncated downloads.

📁

Drag & Drop Interface

Simply drag any game folder or RAR archive directly onto the window to begin dynamic analysis immediately.

📊

Tabbed Diagnostics

Includes color-coded execution logs alongside a structured DataGrid breakdown for per-file size inspection.

🛡️

Path & Space Checks

Checks target drive free space and flags long folder paths (>120 chars) to prevent common Unarc.dll error -11 issues.

🌙

Dark Mode Toggle

Native built-in dark and light UI theme support matching standard modern operating system aesthetics.

📦

Zero External Dependencies

Compiled natively via .NET Framework as a standalone single-file binary with zero required installers.

Building From Source

Compile the application locally on Windows without installing Visual Studio.
